Use case · Orca Note

Orca Note web clipper: articles and highlights, saved as notes in one click

Shunshou is a browser extension (and a userscript). Connect your own Orca repository and a set of "save to Orca" actions appears on the pages you read — a full-page clip becomes a collapsible tree with the title as the parent block and the article as its children, with tags and properties attached; highlights, tasks and Douban books each have their own action.

No account · No server · content goes only to the MCP endpoint you enter

Why it hurts

Getting a web page into your notes usually breaks at these points

Orca itself is a pleasure. The painful part has always been the "web page → notes" leg. These are the things you do every time, and every time they cost you.

⎘

Copy, switch, paste, clean up

Select the article, copy, switch to Orca, find today's daily note, paste, then strip the page's own styling and leftover navigation by hand. By the end of a long read you no longer feel like reading it.

⌗

Tags and properties, attached by hand

If the note is to be findable later it needs the bookmark tag plus link and domain properties — which means opening the property panel, scrolling the tag list and filling each field, every single time.

☰

A long article pastes as one lump

The whole article becomes one enormous block and you scroll forever. To get a "title on top, article folded underneath" structure you have to cut and indent it yourself.

⊜

The same page saved twice

You saved it months ago and forgot. Today you save it again, and only find out when you scroll back through your daily notes and see two near-identical entries.

✂

An interruption kills the highlight

You want to keep a good sentence: switch window, find the daily note, paste — and by the time you're back you've lost your place, or you just skip it.

✓

To-dos scattered across the web

In an issue, a doc, an email: "I need to do this." Close the tab and it's gone — there's nowhere the lot of them collect.

Setup

Three steps to connect your Orca repository

Shunshou talks to Orca's own MCP service — Orca just needs to be running.

Turn on MCP and copy the token

Enable the MCP service in Orca and copy its token — the default endpoint is http://localhost:18672/mcp.

Add an Orca connection

In Shunshou's Connections page, add an Orca connection with the MCP endpoint, the token and your repository ID, then hit Test. A success says "Connected"; a bad token says authentication failed — no guessing.

Configure a tag scheme

Go back to the action and set its content template, tags and properties, destination and insertion position. The shipped bookmark / excerpt / task / clip / one-line-note actions already come with sensible defaults.

Note

Once the connection is configured, the "save to Orca" actions appear where they belong. Before that they sit in the "not configured" section at the bottom of the panel, so they never take up a slot you might click by mistake.

Scenes

The ones people reach for most

These ship out of the box and are clickable as soon as the connection is set up. Fields, templates and cleaning rules for each are edited visually in the Studio.

Full-page clip → a collapsible note tree

The page title becomes the parent block and the article becomes its children, with tags attached to the parent — it opens as a tree you can fold, so a long read is never one lump.

The link is stored as a property via the bookmark tag scheme, and hidden content (including ads hidden by an ad blocker) never enters the clip.

Selected highlight → a one-block note

Select a passage and click "Save as excerpt (Orca)" — the quote plus its source link goes into today's daily note, filed under the excerpt tag.

Read it, keep it, never leave the page and never switch windows.

Save as task

In an issue, an email or a doc, select the sentence that says what needs doing and click "Save as task (Orca)" — it's written into your daily note under the task tag, status TODO by default.

To-dos collect in one place, and scrolling today's note tells you what's outstanding.

Page summary (AI)

"Save as page summary (Orca)" first has your own model summarize the whole article into structured text, then saves it in the same clip shape — title as parent, summary as children.

The prompt is just configuration; change one sentence and it becomes a different job (key points, keywords, counter-arguments…).

Douban books / movies / games → notes

Douban book, movie and game pages each yield 17 / 20 / 11 fields (synopsis, episode count, format, and so on) — one click writes them into Orca.

Fields such as the cover image are attached as properties by the tag scheme.

All highlights on the page, at once

Select text and click Highlight — the marks stay on the page (they survive a reload and don't change the page's structure). When you're done reading, save the whole page's highlights to Orca in one go, or copy them as text.

Collect a few, save them together

Click "Add to staged" on each passage you like, then save the whole batch to Orca at once from the staged area at the top of the orb panel. A count badge on the orb reminds you how many are still waiting.

One-line note

Press Ctrl/⌘ + Shift + K to open the command palette and just type — "Save a note" in the "Use this text…" section stores that sentence in Orca on Enter.

Combines with

It isn't an isolated "clip button"

The Orca destination is one link in the toolbox — it can follow another action, or run on its own.

Both libraries at once (action chains)

An action can carry "then do" steps: save an Orca bookmark, then write a SiYuan database row — one click, both libraries populated. Steps run in order, stop at the first failure, and share one extraction of the page.

Jump back to what you saved (deep links)

A successful save returns an orca-note:// deep link to the block that was just written. Add an "Open link" step to jump straight there, or "Copy to clipboard" to keep the link around.

See it, log it (auto-run)

Douban book / movie / game pages can be set to auto-run "Save as book (Orca)" the moment you open them — browse and it's filed, no click at all. Off by default, enabled per action, and it can ask you first.

Destination and position are yours

Leave the destination empty for today's daily note, give a block ID to insert at a specific spot, or write date:<Unix seconds> for a particular day. Insertion can go at the end, the beginning, after a block or before one.

Property types coerced for you

Missing tags and properties are created automatically and values are coerced to the declared type — dates as Unix seconds, single-select values must be one of the defined choices, block references as an array. Tag properties are attached structurally, so they don't end up as plain text.

Point at it yourself when it's wrong

Bad article? Pick the container on the page (multi-select merges, Enter finishes), then "Save as rule" to promote it to a lasting rule. Or let AI read the page structure and offer candidates — and preview each candidate for free before choosing.

FAQ

Questions about Shunshou + Orca Note

What is Orca Note, and does Shunshou support it?

Orca Note is a local-first outliner note app that ships its own MCP service. Shunshou writes through that MCP endpoint, saving web articles, selected highlights, tasks and book data as note blocks and attaching tags and properties according to the scheme you configure.

Do I have to create the tags and properties in Orca first?

No. Missing tags and properties are created automatically on write, and values are coerced to the declared type (dates as Unix seconds, single-select values must be one of the defined choices, block references as an array). Existing tags are only filled in — your existing property definitions aren't redefined.

What does a saved note look like?

By default it goes to the end of today's daily note. A full-page clip uses the shape of a title parent block with the article as its children, with tags attached to the title, so it opens as a collapsible tree; highlights and tasks are single blocks.

Will the clipped article contain ads and navigation?

No. Clipping counts visible text only and then takes the smallest common ancestor around the article — so a page whose article is a single paragraph doesn't fall back to the whole page, and hidden content (including ads hidden by an ad blocker) never enters the clip.

Built-in article rules cover Douban, GitHub, Bilibili, WeChat articles, SSPAI, X threads and Xiaohongshu; everything else goes through the article engine. When it's wrong you can pick the container yourself on the page, or save that as a lasting rule.

Does my content go through any third-party server?

No. Content goes only to the MCP endpoint you entered — usually your own machine or LAN. Shunshou has no account system and no server; the author receives none of your data.

(When you use the AI summary, the article goes to the model endpoint you configured yourself, and nowhere else.)

Can I jump back to the note in Orca after saving?

Yes. A successful save returns an orca-note:// deep link to the block that was just written. Add an "Open link" step in the action chain to jump straight there, or a "Copy to clipboard" step to keep the link.

Does it cost anything? Do I need an account?

It's free, with no ads and no features locked behind payment, and there's no account to create. Config and secrets stay in your browser, and exported config doesn't carry the secrets.
