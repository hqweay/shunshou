功能

从一页网页，到你自己的笔记

取数、清洗、渲染、投递，四段都能在配置台里看见、当场试算。

划词即用

选中一段话，选区上方就浮出该做的事

只列出真的用到划选的动作，通常就两三个，多了收进 ⋯。点浮条不会清掉选区，滚动、点空白或按 Esc 即消失；不喜欢可以在设置里关掉，悬浮球照常可用。

  • 翻译划一句外语，译文在选区旁就地浮出——不离开页面、不切标签，气泡可拖动、能一键复制
  • 摘录存进虎鲸 / 思源，或复制为 Markdown
  • 分享一张干净的摘录卡片，或直接预填发推文
剪得干净

正文范围可以拾取，站点规则可以改

内置站点规则覆盖豆瓣书影 / GitHub / B 站 / 微信公众号 / 少数派，其余网页走正文引擎自动识别主内容；被隐藏的内容（含广告拦截器藏掉的广告）不会进剪藏。

  • 不对就拾取：在页面上点选正文容器，可多选合并，Enter 完成
  • 一个动作一个范围：「保存正文」与「保存评论」互不干扰
分享图

一段摘录、一篇长文，整页图文顺手就出

四种主题（纸感 / 墨感 / 品牌 / 纯白）、四种尺寸（长图 / 4:5 / 3:4 / 1:1），内容块可增删排序，右下角默认带来源页二维码。正文太长会自动分页，不截断。

  • 预览即工作台：出图后能就地换主题 / 字体、改这次的内容，满意了再存回动作
  • 投递：复制图片 / 保存文件 / 复制文本，多个目标逐个报告状态

还有

该有的都在，且都不必写代码

⛓

接着做：动作链

一个动作跑完接着跑下一步，主步骤成功后按顺序执行。例：存虎鲸书签，接着写一行思源数据库（一次点击，两个库都有）；存完顺手把「《标题》 链接」复制到剪贴板。步骤还能设成「等我确认」——不自动执行，而是在结果面上等你点（比如看完 AI 译文再决定要不要存进笔记）。

有些步骤该等你点头——标成「等我确认」就不跟链跑，而是出现在结果面（翻译气泡、结果弹窗）上，你点了才跑。开箱的「翻译」就带两个：分享图（原文 + 译文）/ 发推（译文 + 链接）。

✦

AI 提取（可选）

接你自己的 OpenAI 兼容模型（DeepSeek / OpenRouter / 硅基流动 / 本地 Ollama 都行）。提示词就是配置：{{content}} 交给模型，产出摘要 / 文案 / 关键词，再像普通变量一样用在任何动作里；开箱含划词翻译（划选 → 就地气泡显示译文）。不开启时完全不依赖 AI。

▤

落到你自己的笔记

虎鲸（MCP）与思源（内核 API）：数据库 / 文档 / 日记 / 文档型数据库四种落点，缺列自动创建、写入前自动查重、图片自动本地化进笔记资源库。连接由你自己填，直连你的服务。

⇄

动作市场

订阅官方目录，按标签或搜索安装别人做好的动作包；依赖与冲突有报告，可检查更新与卸载。动作包是纯数据（动作 / 提取规则 / 提示词），不含代码与密钥。

✎

配置即数据

模式 / 场景 / 动作 / 变量组都是可视配置：改错 ⌘Z 撤销，可导入导出、可分享。字段来源支持选择器、「标签:值」、meta、JSON-LD、URL 正则、划选、模板与「依次尝试」，还能加变换链。

⌘

本机脚本（进阶）

会写 JS 的话可以为某个站点写一小段取数逻辑，入参 { url, title, selection, document }。只存本机、不进配置、不随导出与分享；默认不生效，需你自己在扩展详情页开启。

本地优先

没有账号，没有服务器，不上传你的数据

数据不出你自己的服务

写入笔记、调用模型都直接连你配置的地址，不经过作者。导出配置时不含任何密钥。

没有广告与统计

无广告、无埋点、无崩溃上报。运行记录只在本机，可随时清空，永不导出。

不改页面的样子

悬浮球与面板渲染在扩展自己的 Shadow DOM 里，不修改页面样式与 DOM；剪藏的清洗只作用于页面副本。

安装

三步装好，三分钟上手

下载并解压

到 Releases 下载最新的 shunshou-extension-*.zip，解压到任意目录（不要双击直接运行）。

打开扩展管理页

地址栏输入 chrome://extensions（Edge 为 edge://extensions），打开右上角的「开发者模式」。

加载已解压的扩展

点「加载已解压的扩展程序」，选中解压目录。然后打开任意网页，看右下角。

审核中

Chrome 与 Edge 应用商店已提交审核，通过后这里会换成商店安装按钮，装好即自动更新。 在那之前从 Releases 下载的版本一样能用；有新版本时配置台「关于」页可以手动检查更新， 重新加载一次解压目录即可，配置会保留。

常见问题

你可能想问的

要注册账号吗？

不要。顺手没有账号体系，装好就能用——开箱的「日常」模式零配置可用。

我的数据会去哪？

内容只在两处流动：你主动点的动作，以及你自己配置的笔记 / 模型服务。作者这边没有服务器，收不到你的任何数据。

配置与密钥存本机，导出的配置不含密钥。详见 隐私说明。

支持哪些浏览器？收费吗？

目前是 Chrome / Edge（同一内核）。免费使用，没有广告，也没有需要付费解锁的功能。

需要懂技术才能改动作吗？

不需要。动作、匹配规则、提取字段、内容模板都在配置台里可视化调整，改错可一键撤销。只有「本机脚本」是给会写 JS 的人留的逃生口，不用它也不缺什么。

怎么更新？会不会丢配置？

下载新版本的 zip，重新走一遍「加载已解压的扩展程序」即可，配置会保留。新版本新增的默认场景 / 动作会在下次打开时增量补齐——你改过的不动，删掉的不会回来。

可以自己加站点吗？

可以。加一条网址匹配规则、几个动作，就是一个新场景；想省事也可以从「动作市场」装别人分享的动作包，或把自己配好的场景导出成 .action-pack.json 发给朋友。
