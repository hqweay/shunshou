顺手是一个浏览器扩展（Chrome / Edge），也是一个**油猴脚本**（桌面与手机都能装）：会看你正打开的是什么网页，顺手换成合适的动作——
豆瓣存书影游、B 站收视频与评论、X / 小红书 / Instagram 一键成卡，划词进虎鲸 / 思源笔记；
想分享时，一段摘录、一篇长文，整页图文顺手就出。常做的事还能设成「自动运行」——打开对应网页就替你跑。

- **无账号、无服务器**：配置与密钥只保存在本机；内容只发给你自己配置的笔记 / 模型服务
- **会看场合**：GitHub、豆瓣、B 站、X、小红书、Instagram 等站点自带场景；其余网页有书签、摘录、整页剪藏、分享这些通用动作
- **剪得干净**：内置站点规则（豆瓣书影 / GitHub / B 站 / 微信公众号 / 少数派）开箱就准，其余网页走正文引擎自动识别主内容；不对就「拾取正文」——点选容器（可多选），一次生效，也能存成站点规则
- **存得下来**：剪藏、分享图、正文都能**保存成本地文件**（Markdown / 文本 / 图片）；路径支持变量与子目录，例如 `顺手/{{date:YYYY-MM-DD}}/{{title}}.md`，直接放进 Obsidian / 思源库；装了 Obsidian 还能**一键存进你的库**（`obsidian://` 深链，库内目录可配）
- **划词即用**：选中一段文字，选区上方直接出现「摘录 / 发推文 / 存进笔记」等快捷动作；接上 AI 还能「翻译」——译文在选区旁的浮出气泡里就地显示（气泡可拖动、能复制，看完再决定要不要分享）
- **能串联**：动作可以配「接着做」步骤——一次点击跑完整条链（存虎鲸接着写思源、存完顺手复制链接……）；步骤也能设成「等我确认」，不自动跑、在结果面上等你点
- **能自己动手**：动作可以设成「自动运行」或「仅建议」——打开对应网页就替你跑，或只提醒你一下（默认关、逐动作开，可设延迟、冷却与执行前询问）；链条里还能点按钮、填输入框、等元素出现，把页面元素截成图片
- **不用写代码**：动作、匹配规则、提取字段、内容模板都在配置台里可视化调整，改错可一键撤销
- **可扩展**：可选接入你自己的 AI 模型；还能从「动作市场」装别人做好的动作

## 安装

**浏览器扩展（桌面推荐）：**

**Edge 商店（推荐）**：[顺手 · 会看场合的网页工具](https://microsoftedge.microsoft.com/addons/detail/elhiacffkdkpkcegafabljaldcoimich) 一键安装，装好即自动更新。

**或手动加载**（Chrome 商店审核中，暂用此方式；也适用于其它 Chromium 浏览器）：

1. 到 [Releases](https://github.com/hqweay/shunshou/releases/latest) 下载最新的 `shunshou-extension-*.zip`
2. 解压到任意目录（不要直接双击运行）
3. 打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压目录

> **Edge 商店已上架**；**Chrome 应用商店审核中**，通过后会补上商店链接。

**油猴脚本（手机 / 不想装扩展时）：**

先装一个脚本管理器，再点安装链接即可（脚本管理器会自动检查更新）：

- **桌面**：Chrome / Edge / Firefox 装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
- **Android**：用 [Firefox for Android](https://www.mozilla.org/firefox/browsers/mobile/android/)（或 Kiwi 等支持扩展的浏览器）装 Tampermonkey / Violentmonkey
- **iOS / iPadOS**：Safari 里装 [Userscripts](https://github.com/quoid/userscripts)（App Store 免费）或 Tampermonkey

安装地址（在脚本管理器里新建脚本、粘贴脚本内容亦可）：

**https://github.com/hqweay/shunshou/releases/latest/download/shunshou.user.js**

> **手机上的样子**：注入界面已适配窄屏与触屏——悬浮球在右下角，点一下展开动作面板；钉在球旁的动作在触屏上常显（手机没有悬停）；「页内配置」铺满屏幕。
> 少数依赖桌面浏览器的能力会**显式降级**并说明（浏览足迹只统计当前标签页、保存文件的子目录会拍平、跨标签统计不可用），功能本身不缺席。

## 三分钟上手

1. **打开任意网页**：右下角出现悬浮球；在 GitHub / 豆瓣 / B 站 / X / 小红书等页面，它会自动换成对应场景
2. **划选一段文字**：选区上方浮出小胶囊，直接点「分享摘录 / 发推文 / 存划选摘录」；也可以点悬浮球里的动作。
   划一句外语点「**翻译**」，译文就在选区旁浮出（不离开页面，气泡可拖动）
3. **打开一篇好文章**：点「分享全文」把整页正文与图片排成卡片（超长自动分页，不截断）；
   点「复制网页剪藏」则复制成 Markdown（含图片链接），可直接粘进 Obsidian / Notion / 思源；想直接存成文件，点「**保存 Markdown 到本地**」——落到 `下载/顺手/日期/标题.md`；装了 Obsidian 的话，点「**存到 Obsidian**」直接写进你的库
4. **配置**：悬浮球面板顶部的齿轮「**页内配置**」直接在页面里打开——能对着当前网页试算字段 / 剪藏、拾取正文容器；
   点浏览器工具栏的扩展图标 →「打开配置台」则是独立标签页

## 功能

### 会看场合：站点场景

| 站点 | 顺手能做的 |
|---|---|
| GitHub | 复制 `owner/repo`、生成仓库分享卡片 |
| X（推特） | 推文正文 + 图片：复制文案、生成分享卡片、发推文预填 |
| 小红书 | 笔记标题 / 正文 / **全部图片**（自动补全轮播）与赞藏数：复制文案、生成分享卡片 |
| Instagram | 帖子图片自动补全后排成「图片墙」：复制文案、生成分享卡片（含作者 / 日期 / 点赞） |
| 豆瓣（书 / 影 / 游） | 17 / 20 / 11 个字段自动提取（电影与电视剧通用：形式 / 集数 / 简介等）：复制信息、分享卡片、写进虎鲸 / 思源 |
| B 站视频 | 视频信息 + 评论（含楼中楼）复制、生成分享卡片、存为视频笔记 |
| 任意网页 | 复制 Markdown 链接 / 摘录 / 存为书签或任务、整页剪藏、**保存 Markdown 到本地**、**存到 Obsidian**、AI 总结、**划词翻译**、分享图、发推文；点击 / 填写 / 等待、元素截图（多块 / 拼接长图） |

悬浮球可以拖动吸边、悬停展开常驻动作、在面板顶部手动切换场景，还能整体切换**模式**——模式按用途组织（开箱有
「日常 / 工作 / 学习 / 营销」：日常零配置、工作与学习落笔记、营销出图发帖），一套模式就是一整套场景，
想换整套工作流时切一个模式就行，不用逐个改动作。虎鲸 / 思源 / AI 模型这类后端是全局**连接**，配好就自动出现对应动作。
动作可以分组收纳（开箱就有「分享」「AI」分组），折叠状态会被记住。
还没配好的动作（比如没选笔记连接）会收进面板底部的「未配置」区，配好自动出现。

### 剪得干净：内容范围与站点规则

- **默认就准**：内置站点规则覆盖豆瓣书影 / GitHub / B 站 / 微信公众号 / 少数派；其余网页走正文引擎（Readability）
  自动识别主内容。被隐藏的内容（含广告拦截器藏掉的广告）不会进剪藏
- **不对就拾取**：页内配置 →「站点规则」→「拾取正文」→ 在页面上点选容器（**可多选**，Enter 完成；一个段落 / 短引用也认）
  → 选范围（整站 / 本类页面）→ 保存即生效；「本页诊断」告诉你来源、命中了哪条规则、每块剪了多少字；
  删掉规则即回退系统默认，内置规则也能单独停用
- **一个动作一个范围**：动作展开区「**内容范围**」可以为该动作单独指定——拾取容器（支持多块合并）、
  「每次运行时拾取」，或引用一条站点规则当底稿、只覆盖要改的部分（含 remove / keep 清洗与图片阈值）。
  「保存正文」与「保存评论」两个动作因此互不干扰
- **正文换行**（动作展开区，逐动作）：单换行视为段落 / 段落之间 1 或 2 个换行（思源语义：1 = 同一块内换行，2 = 新块）/
  压缩连续空行——只作用于正文类变量，Markdown 剪藏结构不动；旧版设置在设置页的全局值会在升级后一次性写进各动作

- 点浮条不会清掉你的选区；滚动、点空白或按 `Esc` 即消失；不喜欢可以在设置页关掉，悬浮球照常可用
- **划词翻译（AI）**：划一句 → 点「翻译」→ 选区旁浮出小气泡**就地显示译文**（不离开页面、不切标签）；
  气泡可以**拖动**挪开挡住的正文，也能一键复制。译文满意后，气泡底部还有「分享图 / 发推」——
  **看完再决定**，不会自动替你发出去（需先在配置台配好 AI 连接）
- 想固定某个动作出现在哪里：配置台的动作行里有常驻的 **「面板 · 浮条 · ★」展示簇**（进悬浮球面板 / 进划词浮条 / 钉到球旁）

### 分享

- **分享图**：划选 → 一张干净的卡片；投递由「接着做」的步骤负责——图片留在结果弹窗里按需复制 / 下载，
  也可在动作里再加「保存图片文件」。四种主题（纸感 / 墨感 / 品牌 / 纯白）、
  四种尺寸（长图 / 4:5 / 3:4 / 1:1），内容块可增删排序，右下角默认带来源页二维码
- **预览即工作台**：出图后弹窗预览——「调整」里直接换主题 / 背景色 / 字体、改卡片内容；
  「分享全文」还能就地改这次的正文（只影响本次，不落配置），满意了「保存到动作」；图片太长看不清就点图「查看大图」
- **分享全文 / 网页剪藏**：整页正文与图片**按阅读顺序**排成卡片，超长自动分成多张、不截断
  （图片留在结果弹窗里逐张复制 / 下载全部——不自动占用剪贴板，「复制」就是复制，不会往你磁盘里塞文件）；
  也能一键复制成 Markdown（含图片链接，粘到 Obsidian / Notion / 思源即用）
- **存成本地文件**：整页剪藏 / 分享图 / 文本都能保存成本地文件（Markdown / 文本 / 图片），
  路径支持变量与子目录——如 `顺手/{{date:YYYY-MM-DD}}/{{title}}.md`，直接放进 Obsidian / 思源库；
  同名自动编号，扩展装好「管理下载」权限后也可选覆盖。文件只写进你自己的下载目录，不读、不列举你已有的下载记录
- **存进 Obsidian**：装了 Obsidian 的话，一键把网页剪藏写进你的库——走 `obsidian://` 深链交给 Obsidian 落盘，
  不经过任何服务器；库内路径支持子目录（如 `顺手/{{date:YYYY-MM-DD}}/{{title}}`），同名可追加 / 覆盖，写完默认不跳出笔记。
  填一次库名即可（可留空用当前库）
- **分享到社交平台**：X / 微博 / Bluesky / Telegram / Mastodon / Reddit——打开对方的官方分享框并预填内容，
  不需要账号与凭证，发布前由你在编辑框里确认

### 保存到笔记（可选）

- **虎鲸**：MCP 端点 + Token + 仓库 ID；标签与属性按方案自动创建 / 补齐（类型自动强转）
  - 书签 / 摘录 / 任务：内容形态就是模板，随你改
  - **整页剪藏 / 网页总结**：网页标题为父块（按「书签」标签归档），正文（或 AI 总结）作为它的子块；
    页面信息（链接等）按「书签」标签方案存为属性；网页上被隐藏的内容（含广告拦截器藏掉的广告）不会进剪藏
- **思源**：内核地址（默认 `http://127.0.0.1:6806`）+ API Token，两种落点：
  - **数据库（属性视图）**：写入一行，列方案可视化编辑，缺列自动创建；**保存前自动查重**——已有同名行时
    弹窗问你「更新 / 跳过 / 新建」（默认跳过，保护你手改过的单元格）；**图片列自动本地化**——豆瓣封面等会下载后
    存进思源资源库，数据库里直接显示缩略图，不会裂图（可切「保留原链接」）
  - **文档 / 日记**：先选笔记本，「目标文档」留空就是**当日日记**（自动定位、不存在会新建），
    也可保存到指定文档（找不到会自动新建）；内容与插入位置（文末 / 文首）可配
  - **文档型数据库**：把内容新建为一篇思源文档并**绑定**进所选数据库——可跟随数据库的「条目模板」，
    也可自定义保存路径（如 `/收集/{{dateText}}/{{title}}`）；正文图片默认上传到思源资源库。
    **开箱即用**，并另有一条 **AI 总结**版（先用 AI 把整页正文总结成结构化中文，再落库；需先配好 AI 连接）

### 接着做（动作链）

一个动作可以配一串**后续步骤**：主步骤成功后按顺序执行，任一步失败即停；页面信息只提取一次，整条链共用。

- 例：**双库同存**——存虎鲸书签，接着写一行思源数据库（一次点击，两个库都有）
- 例：**存完顺手分享**——存书签，接着把「《标题》 链接」复制到剪贴板
- **「等我确认」= 结果面上的「下一步」**：有些步骤不该自动跑——比如 AI 译文，你想先看一眼再决定要不要存进
  Anki / 分享。把步骤标成「等我确认」，它就不跟链执行，而是出现在**结果面**上（划词翻译的气泡、结果弹窗），
  你点它才跑。开箱的「翻译」就带两个：分享图（原文 + 译文）/ 发推（译文 + 链接）
- 在配置台「场景」页展开动作即可添加步骤；上面两个例子是现成动作包：配置台 →「**市场**」→ 拉取 → 安装

### 自动化（自动运行 · 网页操作）

每个动作都能设「触发方式」——手动 / **自动运行** / **仅建议**：

- **自动运行**：打开匹配的网页就替你跑，不用再点。默认**关闭**、逐个动作开启，并且可以设
  **延迟**（等页面渲染 / 懒加载完）、**冷却**（最小间隔）、去重范围（每次访问 / 每个文档一次）、
  **执行前询问**（写入笔记这类有副作用的动作推荐打开）。开箱不预置任何自动运行；
  从「动作市场」装来的动作包就算带自动运行，**安装后也默认关闭**——开不开永远由你决定
- **仅建议**：不执行，只在悬浮球上点一个小圆点提醒你「这里有件事可以做」
- **静默网站**：列进「静默网站」的站点一律不自动触发（悬浮球仍可手动打开）。配置台「**运行 → 自动化**」
  一处列出已开启的自动运行、就地调参数、看最近执行，静默名单也在这里

**几个玩法**：

- **看到就当记下**：豆瓣书 / 影 / 游页自动运行「存为电影 / 图书 / 游戏（思源）」——浏览即入库，
  一次点击都不用；想更稳就开着「执行前询问」，确认一下再写
- **展开全文再剪藏**：一个动作串起「**点击**『展开全文』→ **等待**元素出现 → **复制网页剪藏**」，
  折叠评论、懒加载长文都适用
- **划选即搜**：拾取站内搜索框，「**填写输入框**」引用 `{{selection}}`——选中一段话点一下就填进去
  （React 受控搜索框也认）
- **自动留档**：打开某个报表 / 后台页，自动把指定区域**截成 PNG** 保存；也能接在「点开」之后截取
- **拼一张长图**：一次点选**多块**元素逐块截图，或**竖着拼成一张长图**——一整条时间线的多条动态、一页里的多段表格都能拼在一起
- **落库后通知我**：链条收尾加一步「发通知」（Studio「从能力新建」可加），自动跑完告诉你结果

**网页操作三件套**（点击 / 填写 / 等待，链条里的积木）：选择器不用手写——参数旁「**拾取**」到页面上点选即可。
都是**合成事件、尽力而为**：富文本编辑器（Slate / ProseMirror 类）与文件上传不承诺，风控站点可能不响应。

**元素截图**：把页面上任意元素（表格 / 图表 / 卡片）截成 PNG，接着复制或保存；选择器同样用「拾取」——
支持**一次多选多块**逐张导出，或**竖向拼接成一张长图**。

### AI 提取（可选）

接你自己的 OpenAI 兼容模型（DeepSeek / OpenRouter / 硅基流动 / 本地 Ollama 都行）：

- **提示词就是配置**：`{{content}}`（划选优先，没划选用整页）、`{{page.clip}}`（整页剪藏）交给模型，
  产出摘要 / 推文文案 / 关键词等**自定义字段**；字段像普通变量一样用在任何动作模板里
- 开箱就有能直接用的动作：「总结并发推文」（划选 → AI 总结 → 打开 X 预填）、「复制 AI 摘要」、「AI 摘要卡片」、
  **「划词翻译」**（划选 → 就地气泡显示译文，看完还能分享图 / 发推），以及把整页 AI 总结落进虎鲸的
  「存为网页总结（虎鲸）」；只有一个 AI 连接时自动绑上
- 调用前有进度提示，结果会话内缓存（不重复扣费）；没绑好连接的动作收在「未配置」区；内容只会发送到**你自己配置的端点**

### 动作市场

- 配置台「市场」页订阅官方目录：**拉取 → 按标签 / 搜索 → 安装**；工具类动作自动并入「始终出现」层，
  站点包装成新场景；依赖与冲突有报告
- 已安装的可以「检查更新」与「卸载」（随包带来的变量组 / 提示词只在没有引用时清理）
- 动作包是**纯数据**（动作 / 提取规则 / 提示词），不含代码与密钥；也可以把你配好的场景导出成
  `.action-pack.json` 分享给朋友

### 配置台与提取

配置台有「场景 / 市场 / 提取 / 连接 / 运行 / 设置 / 致谢 / 关于」八页；所有修改即时生效，**Ctrl/⌘+Z 撤销、Ctrl/⌘+Shift+Z 重做**（会话内 50 步）。

「提取」页把「网页 → 变量」变成可视化配置：字段来源 = 选择器 / 「标签:值」/ meta / JSON-LD / URL 正则 / 划选 /
模板 / 依次尝试（fallback 链），可加变换链（修剪 / 替换 / 正则提取 / 截断 / 分割 / 默认值）；
开箱 5 个**系统变量组**（GitHub、网页 Meta、豆瓣书影游），点「覆盖」就能改，默认只对当前站点生效、其它站点自动回退系统版。

## 更新

**扩展**：下载最新 zip，重新走一遍「加载已解压的扩展程序」即可（配置会保留）。
**油猴**：脚本管理器会自动检查更新，一般无需手动操作。

也可以在配置台「**关于**」页点「**检查更新**」看看有没有新版本；新版本新增的默认场景 / 动作会在下次打开时
增量补齐——你改过的不动，删掉的不会回来。
