顺手是一个浏览器扩展（Chrome / Edge）：会看你正打开的是什么网页，顺手换成合适的动作——
豆瓣存书影游、B站收视频与评论、划词进虎鲸 / 思源笔记；想分享时，一条推文、一张卡片，顺手就出。

- **无账号、无服务器**：配置与密钥只保存在本机；内容只发给你自己配置的笔记 / 模型服务
- **会看场合**：GitHub、豆瓣、B站等站点自带场景；其余网页有书签、摘录、分享这些通用动作
- **划词即用**：选中一段文字，选区上方直接出现「引用 / 存笔记 / 分享图」等快捷动作
- **能串联**：动作可以配「接着做」步骤——一次点击跑完整条链（存虎鲸接着写思源、存完顺手复制链接……）
- **不用写代码**：动作、匹配规则、提取字段、内容模板都在配置台里可视化调整
- **可扩展**：可选接入你自己的 AI 模型；还能从「动作市场」装别人做好的动作

## 安装

1. 到 [Releases](https://github.com/hqweay/shunshou/releases/latest) 下载最新的 `shunshou-extension-*.zip`
2. 解压到任意目录（不要直接双击运行）
3. 打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压目录

> 当前通过 GitHub Releases 分发；Chrome 应用商店上架是后续计划。

## 三分钟上手

1. 打开任意网页：右下角出现悬浮球；在 GitHub / 豆瓣 / B站 等页面会自动换成对应场景
2. **划选一段文字**：选区上方会弹出小浮条，直接点「引用 / 存笔记 / 做成分享图」；也可以点悬浮球里的动作
3. 配置：点浏览器工具栏的扩展图标 →「配置」（独立标签页，每一步修改都可撤销 / 重做）

## 功能

### 站点场景（开箱即用）

| 站点 | 顺手能做的 |
|---|---|
| GitHub | 复制 `owner/repo`、生成仓库分享卡片 |
| Instagram | 帖子图片自动补全后排成「图片墙」：复制文案、生成分享卡片（含作者 / 日期 / 点赞） |
| 豆瓣（书 / 影 / 游） | 17 / 20 / 11 个字段自动提取（电影与电视剧通用：形式 / 集数 / 简介等）：复制信息、存为书签卡片、写进思源数据库 |
| B 站视频 | 视频信息 + 评论（含楼中楼）复制；存为视频笔记 |
| 任意网页 | 复制 Markdown 链接、引用（带来源）、摘录、存为书签 / 任务 |

### 划词浮条

选中网页文字，选区上方会出现一排快捷动作（引用、存进笔记、做成卡片……），点一下就走：

- 只显示**真正用到划选**的动作，通常就三个，不会刷屏；
- 点浮条不会清掉你的选区；滚动、点空白或按 `Esc` 即消失；
- 想固定某个动作的展示位置：配置台「场景」页的动作行里有常驻的 **「面板 · 浮条 · ★」展示簇**（进悬浮球面板 / 进划词浮条 / 钉到球旁）；
- 不喜欢可以在设置页关掉——悬浮球照常可用。

### 分享

- **分享图**：划选 → 一张干净的卡片（三种主题、四种尺寸，内容块可增删排序），默认复制到剪贴板，也可下载
- **分享到社交平台**：X / 微博 / Bluesky / Telegram / Mastodon / Reddit——打开对方的官方分享框并预填内容，
  不需要账号与凭证，发布前由你在编辑框里确认

### 保存到笔记（可选）

- **虎鲸**：MCP 端点 + Token + 仓库 ID；标签与属性按方案自动创建 / 补齐（类型自动强转）
- **思源**：内核地址（默认 `http://127.0.0.1:6806`）+ API Token；支持两种落点：
  - **数据库（属性视图）**：写入一行，列方案可视化编辑，缺列自动创建；**保存前自动查重**——已有同名行时
    **默认只提示、不写入**（保护你手动改过的数据），可在动作里切换为「更新同名行 / 总是新建」；
    **图片列自动本地化**——豆瓣封面等会下载后存进思源资源库，数据库里直接显示缩略图，
    不会因为防盗链裂图（可切「保留原链接」）
  - **文档 / 日记**：先选笔记本，「目标文档」留空就是**当日日记**（自动定位、不存在会新建），
    也可保存到指定文档（找不到会自动新建）；内容与插入位置（文末 / 文首）可配

### 接着做（动作链）

一个动作可以配一串**后续步骤**：主步骤成功后按顺序执行，任一步失败即停；页面信息只提取一次，整条链共用。

- 例：**双库同存**——存虎鲸书签，接着写一行思源数据库（一次点击，两个库都有）
- 例：**存完顺手分享**——存书签，接着把「《标题》 链接」复制到剪贴板
- 在配置台「场景」页展开动作即可添加步骤；上面两个例子是现成动作包：配置台 →「**市场**」→ **拉取 → 安装**，
  装上即并入「始终出现」层（双库同存需要先配好虎鲸 + 思源两个连接，并给思源步骤选一个数据库）

### AI 提取（可选）

接你自己的 OpenAI 兼容模型（DeepSeek / OpenRouter / 硅基流动 / 本地 Ollama 都行）：

- **提示词就是配置**：`{{content}}`（划选优先，没划选用整页）交给模型，产出摘要 / 推文文案 / 关键词等**自定义字段**
- 字段像普通变量一样用在任何动作模板里；调用前有进度提示，结果会话内缓存（不重复扣费）
- 不接模型也能用其它全部功能；内容只会发送到**你自己配置的端点**

### 使用记录（本地）

配置台「运行」页记录每个动作的使用情况：次数、成败、耗时，配近 7 天趋势、12 周热力图、常用动作，
以及「从未用过」的动作清单（方便收拾配置）。

- **只保存在本机**，不含网页内容；随时可一键清空（见 [隐私说明](PRIVACY.md)）

### 动作市场

- 配置台「市场」页订阅官方动作市场：**拉取 → 选中 → 安装**；工具类动作会自动并入「始终出现」层
- 市场里有「基础摘录」「AI 总结与分享」「双库同存」「存完顺手分享」等现成动作；也可以把你自己配好的场景导出、分享给朋友
- 动作包是**纯数据**（动作 / 提取规则 / 提示词），不含代码与密钥

## 更新

下载最新 zip，重新走一遍「加载已解压的扩展程序」即可（配置会保留）。

也可以先在配置台「**关于**」页点「**检查更新**」看看有没有新版本——只在你点击时请求 GitHub 的公开版本信息。

## 隐私

顺手不收集、不上传任何数据；没有账号，也没有服务器。配置与密钥只在本机，
写入笔记 / 调用模型都直接连你配置的服务。详见 [隐私说明](PRIVACY.md)。
