顺手是一个浏览器扩展（Chrome / Edge）：会看你正打开的是什么网页，顺手换成合适的动作——
豆瓣存书影游、B 站收视频与评论、X / 小红书 / Instagram 一键成卡，划词进虎鲸 / 思源笔记；
想分享时，一段摘录、一篇长文，整页图文顺手就出。

- **无账号、无服务器**：配置与密钥只保存在本机；内容只发给你自己配置的笔记 / 模型服务
- **会看场合**：GitHub、豆瓣、B 站、X、小红书、Instagram 等站点自带场景；其余网页有书签、摘录、整页剪藏、分享这些通用动作
- **划词即用**：选中一段文字，选区上方直接出现「摘录 / 发推文 / 存进笔记」等快捷动作
- **能串联**：动作可以配「接着做」步骤——一次点击跑完整条链（存虎鲸接着写思源、存完顺手复制链接……）
- **不用写代码**：动作、匹配规则、提取字段、内容模板都在配置台里可视化调整，改错可一键撤销
- **可扩展**：可选接入你自己的 AI 模型；还能从「动作市场」装别人做好的动作

## 安装

1. 到 [Releases](https://github.com/hqweay/shunshou/releases/latest) 下载最新的 `shunshou-extension-*.zip`
2. 解压到任意目录（不要直接双击运行）
3. 打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压目录

> 当前通过 GitHub Releases 分发；Chrome 应用商店上架是后续计划。

## 三分钟上手

1. **打开任意网页**：右下角出现悬浮球；在 GitHub / 豆瓣 / B 站 / X / 小红书等页面，它会自动换成对应场景
2. **划选一段文字**：选区上方浮出小胶囊，直接点「分享摘录 / 发推文 / 存划选摘录」；也可以点悬浮球里的动作
3. **打开一篇好文章**：点「分享全文」把整页正文与图片排成卡片（超长自动分页，不截断）；
   点「复制网页剪藏」则复制成 Markdown（含图片链接），可直接粘进 Obsidian / Notion / 思源
4. **配置**：点浏览器工具栏的扩展图标 →「配置」（独立标签页）；悬浮球底部的「页内配置」可以在页面里打开，
   提取字段能直接对着当前网页试算

## 功能

### 会看场合：站点场景

| 站点 | 顺手能做的 |
|---|---|
| GitHub | 复制 `owner/repo`、生成仓库分享卡片 |
| X（推特） | 推文正文 + 图片：复制文案、生成分享卡片、发推文预填 |
| 小红书 | 笔记标题 / 正文 / **全部图片**（自动补全轮播）与赞藏数：复制文案、生成分享卡片 |
| Instagram | 帖子图片自动补全后排成「图片墙」：复制文案、生成分享卡片（含作者 / 日期 / 点赞） |
| 豆瓣（书 / 影 / 游） | 17 / 20 / 11 个字段自动提取（电影与电视剧通用：形式 / 集数 / 简介等）：复制信息、分享卡片、写进虎鲸 / 思源 |
| B 站视频 | 视频信息 + 评论（含楼中楼）复制、生成分享卡片、存为视频笔记 |
| 任意网页 | 复制 Markdown 链接 / 摘录 / 存为书签或任务、整页剪藏、AI 总结、分享图、发推文 |

悬浮球可以拖动吸边、悬停展开常驻动作、在面板顶部手动切换场景，还能整体切换**模式**——一套模式就是一整套场景
（开箱有「混合 / 思源 / 虎鲸」，换工作流时不用逐个改动作）。动作可以分组收纳（开箱就有「分享」「AI」分组），折叠状态会被记住。
还没配好的动作（比如没选笔记连接）会收进面板底部的「未配置」区，配好自动出现。

### 划词即用

选中网页文字，选区上方浮出小胶囊——只列出**真的用到划选**的动作（通常就两三个，多了收进 `⋯`）：

- 点浮条不会清掉你的选区；滚动、点空白或按 `Esc` 即消失；不喜欢可以在设置页关掉，悬浮球照常可用
- 想固定某个动作出现在哪里：配置台的动作行里有常驻的 **「面板 · 浮条 · ★」展示簇**（进悬浮球面板 / 进划词浮条 / 钉到球旁）

### 分享

- **分享图**：划选 → 一张干净的卡片，默认复制进剪贴板，也可下载。四种主题（纸感 / 墨感 / 品牌 / 纯白）、
  四种尺寸（长图 / 4:5 / 3:4 / 1:1），内容块可增删排序，右下角默认带来源页二维码
- **预览即工作台**：出图后弹窗预览——「调整」里直接换主题 / 背景色 / 字体、改卡片内容；
  「分享全文」还能就地改这次的正文（只影响本次，不落配置），满意了「保存到动作」；图片太长看不清就点图「查看大图」
- **分享全文 / 网页剪藏**：整页正文与图片**按阅读顺序**排成卡片，超长自动分成多张、不截断
  （默认复制第一张、其余自动下载）；也能一键复制成 Markdown（含图片链接，粘到 Obsidian / Notion / 思源即用）
- **分享到社交平台**：X / 微博 / Bluesky / Telegram / Mastodon / Reddit——打开对方的官方分享框并预填内容，
  不需要账号与凭证，发布前由你在编辑框里确认

### 保存到笔记（可选）

- **虎鲸**：MCP 端点 + Token + 仓库 ID；标签与属性按方案自动创建 / 补齐（类型自动强转）
  - 书签 / 摘录 / 任务：内容形态就是模板，随你改
  - **整页剪藏 / 网页总结**：网页标题为父块（按「书签」标签归档），正文（或 AI 总结）作为它的子块；
    页面信息（链接等）按「书签」标签方案存为属性；网页上被隐藏的内容（含广告拦截器藏掉的广告）不会进剪藏
- **思源**：内核地址（默认 `http://127.0.0.1:6806`）+ API Token，两种落点：
  - **数据库（属性视图）**：写入一行，列方案可视化编辑，缺列自动创建；**保存前自动查重**——已有同名行时
    弹窗问你「更新 / 跳过 / 新建」（默认跳过，保护你手改过的单元格）；**图片列自动本地化**——豆瓣封面等会下载后
    存进思源资源库，数据库里直接显示缩略图，不会因防盗链裂图（可切「保留原链接」）
  - **文档 / 日记**：先选笔记本，「目标文档」留空就是**当日日记**（自动定位、不存在会新建），
    也可保存到指定文档（找不到会自动新建）；内容与插入位置（文末 / 文首）可配

### 接着做（动作链）

一个动作可以配一串**后续步骤**：主步骤成功后按顺序执行，任一步失败即停；页面信息只提取一次，整条链共用。

- 例：**双库同存**——存虎鲸书签，接着写一行思源数据库（一次点击，两个库都有）
- 例：**存完顺手分享**——存书签，接着把「《标题》 链接」复制到剪贴板
- 在配置台「场景」页展开动作即可添加步骤；上面两个例子是现成动作包：配置台 →「**市场**」→ 拉取 → 安装

### AI 提取（可选）

接你自己的 OpenAI 兼容模型（DeepSeek / OpenRouter / 硅基流动 / 本地 Ollama 都行）：

- **提示词就是配置**：`{{content}}`（划选优先，没划选用整页）、`{{page.clip}}`（整页剪藏）交给模型，
  产出摘要 / 推文文案 / 关键词等**自定义字段**；字段像普通变量一样用在任何动作模板里
- 开箱就有能直接用的动作：「总结并发推文」（划选 → AI 总结 → 打开 X 预填）、「复制 AI 摘要」、「AI 摘要卡片」，
  以及把整页 AI 总结落进虎鲸的「存为网页总结（虎鲸）」；只有一个 AI 连接时自动绑上
- 调用前有进度提示，结果会话内缓存（不重复扣费）；没绑好连接的动作收在「未配置」区；内容只会发送到**你自己配置的端点**

### 动作市场

- 配置台「市场」页订阅官方目录：**拉取 → 按标签 / 搜索 → 安装**；工具类动作自动并入「始终出现」层，
  站点包装成新场景；依赖与冲突有报告
- 已安装的可以「检查更新」与「卸载」（随包带来的变量组 / 提示词只在没有引用时清理）
- 动作包是**纯数据**（动作 / 提取规则 / 提示词），不含代码与密钥；也可以把你配好的场景导出成
  `.action-pack.json` 分享给朋友

### 配置台与提取

配置台有「场景 / 市场 / 提取 / 连接 / 运行 / 设置 / 关于」七页；所有修改即时生效，**Ctrl/⌘+Z 撤销、Ctrl/⌘+Shift+Z 重做**（会话内 50 步）。

「提取」页把「网页 → 变量」变成可视化配置：字段来源 = 选择器 / 「标签:值」/ meta / JSON-LD / URL 正则 / 划选 /
模板 / 依次尝试（fallback 链），可加变换链（修剪 / 替换 / 正则提取 / 截断 / 分割 / 默认值）；
开箱 5 个**系统变量组**（GitHub、网页 Meta、豆瓣书影游），点「覆盖」就能改，默认只对当前站点生效、其它站点自动回退系统版。

- 「关于」页可以手动**检查更新**（只在你点击时请求 GitHub 的公开版本信息）

## 更新

下载最新 zip，重新走一遍「加载已解压的扩展程序」即可（配置会保留）。

也可以在配置台「**关于**」页点「**检查更新**」看看有没有新版本；新版本新增的默认场景 / 动作会在下次打开时
增量补齐——你改过的不动，删掉的不会回来。

## 隐私

顺手不收集、不上传任何数据；没有账号，也没有服务器。配置与密钥只在本机，
写入笔记 / 调用模型都直接连你配置的服务。详见 [隐私说明](PRIVACY.md)。
